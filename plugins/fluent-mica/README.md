# Fluent Mica

A Fluent 2 Stash theme with a dark Mica foundation, translucent Acrylic surfaces, and a Fluent accent palette. It is derived from the actual [Stash Refract theme](https://github.com/ordureconnoisseur/stash-refract), upstream version 1.24.3 at commit `5a14edb`.

Fluent Mica keeps Refract's tested Stash page layout, responsive top navigation, card layouts, filters, player and detail-page styling. The material layer and color tokens are restyled for Fluent 2; the default accent is Blue, with Teal, Green, Yellow, Orange, Red, Pink, and Purple also available.

The quick accent picker is in **Settings → Plugins → Fluent Mica**. Full theme settings are also available in **Settings → Interface → Fluent Mica**. The theme starts in dark mode; Refract's optional light and Lite modes remain available.

Install from the repository source in the root README or [download the 1.0.0 manual archive](../../packages/fluent-mica/1.0.0-manual.zip) and extract the `fluent-mica/` directory into Stash's configured plugins directory. Enable Fluent Mica after installation. Disable other full-app themes while using it so their global styles do not conflict.
