# Cinema Catalog

A dark, media-first UI theme for Stash. It preserves Stash's routes and controls while moving the primary navigation into a desktop sidebar and a mobile slide-out drawer. Media cards remain image-led with compact metadata and visible progress indicators.

The accent picker is in **Settings → Plugins → Cinema Catalog**. It offers Blue, Teal, Green, Yellow, Orange, Red, Pink, and Purple. The selected accent applies immediately and is cached locally.

Cinema Catalog is UI-only; it has no server executable or database migration. Install it from the repository source described in the root README, or [download the 0.1.2 manual archive](../../packages/cinema-catalog/0.1.2-manual.zip) and extract its `cinema-catalog/` folder into Stash's configured plugins directory.
