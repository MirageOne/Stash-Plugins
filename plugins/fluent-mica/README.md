# Fluent Mica

A Fluent 2 Stash theme with a dark Mica foundation, translucent Acrylic surfaces, and a Fluent accent palette. It is derived from the actual [Stash Refract theme](https://github.com/ordureconnoisseur/stash-refract), upstream version 1.24.3 at commit `5a14edb`.

Fluent Mica keeps Refract's tested Stash page layout, responsive top navigation, card layouts, filters, player and detail-page structure. Fluent 2 styling uses Mica for page and card surfaces, Acrylic for floating controls, Segoe UI typography, compact corners, restrained selection states and the Fluent accent palette. The default accent is Blue, with Teal, Green, Yellow, Orange, Red, Pink, and Purple also available.

Scene video cards use one full-width column on mobile. Desktop scene lists use wider cards with a 360px minimum column width, reducing the number of columns on typical screens. Fresh installs use the restrained rating treatment; the optional Extravagant flourish remains available in plugin settings.

Scrolling uses a lighter Acrylic blur and cards no longer lift or animate large shadows as they pass under the pointer. Performer titles use a consistent size with ellipsis for long names, and favorites use a compact, always-visible heart instead of floating heart particles.

Performer nameplates now size to the title instead of filling the card, while long names stop before the favorite control. The favorite button is vertically centered with the name. Pagination page counts stay on one line at narrow widths.

The quick accent picker is in **Settings → Plugins → Fluent Mica**. Full theme settings are also available in **Settings → Interface → Fluent Mica**. The theme starts in dark mode; Refract's optional light and Lite modes remain available.

Install from the repository source in the root README or [download the 1.0.4 manual archive](../../packages/fluent-mica/1.0.4-manual.zip) and extract the `fluent-mica/` directory into Stash's configured plugins directory. Enable Fluent Mica after installation. Disable other full-app themes while using it so their global styles do not conflict.
