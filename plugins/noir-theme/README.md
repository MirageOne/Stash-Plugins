# Noir

A modern, dark video-library theme for Stash, with a flat charcoal palette, violet accent, and the Archive Monogram brand mark. It is derived from the actual [Stash Refract theme](https://github.com/ordureconnoisseur/stash-refract), upstream version 1.24.3 at commit `5a14edb`.

The redesign replaces the desktop route row with a persistent left sidebar. The home page leads with a wide, up-to-five-scene spotlight carousel above Stash’s customizable recommendation shelves. It advances every eight seconds, with arrows, position indicators, touch swipe, and a pause control; it pauses while hovered or focused, when the page is hidden or offscreen, and by default when reduced motion is enabled. The carousel control lets users explicitly resume rotation despite that preference. It prefers scenes outside the visible shelf and hides featured duplicates when it needs to draw from that shelf. Scene and image detail pages put their primary media in the wide left column and metadata tabs in a right rail. Gallery detail pages give the image grid the wide column and keep gallery information in the rail. At tablet and phone widths, media comes first and native tabs follow underneath. Performer profiles use a compact portrait header with real scene, image, and gallery counts, favorite and edit actions, an About section, and filmography. The Statistics page presents linked library totals, scenes by year, a resolution breakdown, and expandable playback and storage details, with larger category icons and easier-to-read labels and chart text. Stash still owns the underlying player, filters, metadata, favorites, editing tools, and navigation actions. Settings menus use flat charcoal surfaces with a restrained violet selection, and their action buttons follow the same style. The desktop sidebar can collapse to icons. Settings → Interface → Noir lets users choose its Stash routes and supported actions; plugin page links remain in the top bar and mobile drawer. Mobile uses a single-column scene and performer layout plus a configurable bottom dock. The default palette uses deep charcoal surfaces and Violet (#8b5cf6); Teal, Green, Yellow, Orange, Red, Pink, and Blue remain available in the accent picker.

The interface uses opaque near-black and charcoal surfaces, restrained violet active states, compact corners, and system sans-serif typography. Buttons, switch controls, and status actions use flat surfaces without Fluent gradients or glow; their keyboard focus remains visible, and alternate accent and light-mode settings are respected. The Archive Monogram’s violet segment follows the selected accent color.

Scene video cards use one full-width column on mobile. Performer cards also switch to one full-width column on phones so names, favorites, and stats have room; compact two-column cards remain on wider tablets. Desktop scene lists use wider cards with a 360px minimum column width, reducing the number of columns on typical screens. Fresh installs use the restrained rating treatment; the optional Extravagant flourish remains available in plugin settings.

Scrolling uses reduced blur and cards no longer lift or animate large shadows as they pass under the pointer. Performer titles use a consistent size with ellipsis for long names, and favorites use a compact, always-visible heart. Performer nameplates size to the title, long names stop before the favorite control, and the favorite button is vertically centered with the name. Pagination page counts stay on one line at narrow widths.

The quick accent picker is in **Settings → Plugins → Noir**. Full theme settings are also available in **Settings → Interface → Noir**, including sidebar collapse, sidebar destinations, mobile dock items, and existing card and player options. The theme starts in dark mode; optional light and Lite modes remain available.

Install from the repository source in the root README or [download the 1.1.7 manual archive](../../packages/noir-theme/1.1.7-manual.zip) and extract the `noir-theme/` directory into Stash’s configured plugins directory. Enable Noir after installation. Disable other full-app themes while using it so their global styles do not conflict.
