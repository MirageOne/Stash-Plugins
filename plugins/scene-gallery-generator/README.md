# Scene Gallery Generator

Scene Gallery Generator extracts still frames from videos already indexed by Stash, scans the generated images into the selected image library, and creates or refreshes a Stash gallery linked to the source scene. It uses the local video file and Stash's configured FFmpeg; it does not download artwork from scraper sites.

## Use

Open **Scene Gallery Generator** from the utility buttons beside Settings in Stash. Choose an image-enabled library and set **Images per scene** to any value from **1 to 30** (8 by default). The value applies to the library run and can be changed before every run. **Smart** sampling looks for scene changes in a low-resolution pass, avoids detected black frames, skips near-identical samples where possible, and fills gaps with evenly spaced frames. Choose **Evenly spaced** for a faster run without scene-change analysis. Both modes avoid the first and last 6% of the video.

Use **Generate or update galleries** to process the library. The scene table shows each scene's task status as **Running**, **Queued**, **Completed**, or **Failed** while the per-scene jobs are processed. A scene is skipped only when its ZIP images are indexed, present in the gallery, and linked to the scene at the requested image count and sampling mode. Incomplete or unlinked galleries are refreshed. Use **Generate** or **Refresh** beside a scene to process only that scene. The page shows the Stash job's progress, and jobs can be cancelled.

For each scene, the plugin stores output beneath the selected image library in `Scene Gallery Generator/sgg-scene-<scene-id>/`. The ZIP is named after the scene (with characters unsafe for filenames replaced), and contains the generated JPEG frames. Stash scans the ZIP and creates the Gallery from its contents. Before rescanning, the plugin removes stale generated files and metadata so the archive's images, Gallery, and scene links stay in sync. It copies supported scene metadata to the Gallery and archive images, then verifies the Gallery metadata, both Gallery-to-scene links, and each archive image's Gallery association. A small manifest records the Gallery ID, archive name, image count, sampling mode, and generated frame names so reruns update the same Gallery.

## Automatic generation

Automatic generation is optional and off by default. To enable it, open **Stash → Settings → Plugins → Scene Gallery Generator** and set **Automatically generate galleries for new scenes**. The **Default images per scene** setting controls images generated by the scene-create hook; the page's numeric input controls manual and library runs. **Image library path** can select the library used by automatic runs; if empty, the first image-enabled library is used.

## Requirements and behavior

- Stash's server process needs Python 3.8 or newer and access to the configured FFmpeg binary. Smart sampling can take longer because it analyzes the video before extracting frames.
- The generated output path must be inside an existing Stash library that allows images. The plugin validates this before writing files.
- A scene must have a video file with a usable duration. Scenes without one are skipped in a library run.
- Gallery metadata includes the scene title, details, date, URL, rating, studio, performers, and tags where the installed Stash schema supports those fields. Frame images receive the image fields supported by that Stash version.
- Stash must scan ZIP archives in the selected image library. Generated frames live inside the scene-named ZIP, avoiding duplicate loose-image entries.
- Generated galleries use the title `<scene title> — Scene Gallery` and a stable `SGG-<scene-id>` code when supported. The video source is never modified.

Install from the repository source in the root README or download the [1.0.5 manual archive](../../packages/scene-gallery-generator/1.0.5-manual.zip) and extract the `scene-gallery-generator/` directory into Stash's configured plugins directory. Enable the plugin in **Settings → Plugins**. If updating manually, reload Stash's plugins and reopen the plugin page so its versioned assets load.

The page follows supported host theme styling for its surfaces, typography, borders, and accent color.
